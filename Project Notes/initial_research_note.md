# Initial Research Note

Date: 2026 01 07

## Aim

I want to analyse running gait over time to understand what changes between better and worse runs.

The practical motivation is 3 parts:
• spot meaningful changes that might indicate rising strain or injury risk
• compare good runs to bad runs to understand what drift looks like
• use the information to support coaching choices that improve efficiency and reduce fatigue

## Working idea

If running gait has stable patterns for an individual, then changes in those patterns across sessions may be measurable.

Some changes will be noise. Others may reflect fatigue, load, terrain, pacing, or emerging niggles. The early work is about learning which is which.

## What I think needs to exist

At a high level, this seems to need:
• a consistent way to capture running movement data
• a way to break recordings into comparable segments
• a small set of gait features that can be tracked over time
• a way to compare sessions and highlight meaningful deltas

## What I will explore first

• what a sensible baseline run looks like
• how much normal variation exists within a single run
• how variation changes when tired, when pace changes, or when terrain changes
• what simple summary views make changes obvious without over analysing

## Notes on interpretation

This is not a clinical or diagnostic exercise. Any signals found would be treated as indicators for attention and learning, not medical conclusions.

## Next steps

• define what a baseline capture looks like and repeat it across multiple runs
• start a simple comparison method between sessions
• keep a running list of candidate gait features and retire the ones that do not behave well
