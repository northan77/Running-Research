## Sprint work summarised (what changed after capture)

The development work that turned this run into a usable validation dataset can be summarised into 3 themes.

### 1. Toe off became a first class artefact
Toe off outputs were promoted from an internal detection idea into a stable derived product:
- toe off event tables are exported
- toe off is linked to strides
- toe off can be overlaid on truth plots
- multiple toe off candidate definitions can be compared

This change made toe off measurable and testable, rather than assumed.

### 2. Stride features became canonical
A single stride feature table was established as the stable downstream contract.

This prevents drift where different tools compute slightly different stride summaries.
It also enables clean comparisons between runs and detection versions.

### 3. Regime segmentation was introduced as a necessary foundation
It became clear that even on a treadmill, stride behaviour changes across the run.
Segmentation was therefore defined as a required stage so:
- stable cadence blocks can be analysed separately
- comparisons do not mix incompatible regimes
- toe off validation can be performed within consistent conditions

## What was observed

### 1. Toe off behaviour is structured, not random
Toe off outputs form coherent clusters and show cadence linked behaviour.
This indicates that detection is selecting a consistent feature in the signals rather than outputting noise.

### 2. There are distinct regimes within the run
Despite being treadmill based, the run shows regime changes.
This is visible as:
- clustering in toe off ratio vs cadence
- distinct cadence bands and behavioural shifts
- outlier clusters rather than uniform scatter

This supports the decision to treat segmentation as a first class requirement.

### 3. Ratio space can exaggerate variability at higher cadence
Toe off ratio scatter increases at higher cadence.
However, when toe off is viewed in time domain (seconds after strike), some cadence bands are tighter than they appear in ratio space.

This demonstrates an important validation principle:

Always validate event timing in both normalised phase (ratio) and absolute time.

### 4. Toe off candidate definitions differ meaningfully
Comparing TO2 against TO1 shows:
- a consistent bias
- measurable spread

This is important because it proves toe off is still a research output.
It cannot yet be assumed true enough to be a stable dependency for later stages without confidence and rejection logic.

## Conclusions

1. This run can now be processed end to end into deterministic artefacts suitable for validation.
2. Toe off detection outputs show structured cadence linked behaviour, supporting that the detector is not arbitrary.
3. Toe off timing and phase vary across regimes, so toe off cannot be treated as a single fixed assumption across the entire run.
4. Toe off must be treated as an explicitly validated artefact with confidence gating before it becomes a dependency.

---

## Validation keys (do not forget)

The following rules were proven necessary during this run:

- validate toe off in both ratio and time domain
- do not judge global scatter without segmentation
- look for within regime stability, not universal uniformity
- compare toe off definitions using agreement plots before committing to one
- prefer failure safe behaviour (reject or lower confidence) over forcing outputs
